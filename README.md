# Photo-Sort
A simple photo sort script with a swift UI where you can devide photos from one folder into folder A and folder B. For more information, check the readme.


How to install:

You dont. You just unzip this Folder somewhere, but Keep all the files like this. Then to open the tool, just douple click on "photosort.jar".


# How to use:

Place your desired photos in the photos Folder, and Keep the Folder A and B empty.
Open the .jar file
To move a photo to Folder A, press the "Left Arrow key"
To move a photo to Folder B, press the "Right Arrow key"
When your finished, a message will appear.
